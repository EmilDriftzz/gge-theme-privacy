# gge-theme-privacy

Privacy Policy — GGE Custom Theme by Driftzz
The extension processes Goodgame Empire images and textures locally in your browser to apply visual themes. Theme preferences are stored locally using Chrome’s storage API.
No personal information, login credentials, messages, or browsing history are collected. No data is transmitted to the developer or third parties. The extension contains no analytics, advertising, or tracking.
Processed game images remain in your browser. Locally stored preferences can be removed by uninstalling the extension.
Last updated: October 3, 2026.
